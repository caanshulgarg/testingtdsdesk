## How the pack is used

1. The owner reads 01–04 first. The scope and the Statement of Applicability decide everything else.
2. Each policy gets an owner, a version and an approval date in its header.
3. Evidence the auditor will ask for is named in each document under **Evidence**.
4. The ISMS runs for at least one internal audit cycle and one management review before the Stage 1 audit. A realistic timeline is 3–4 months from approval.
