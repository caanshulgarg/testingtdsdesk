## General notes (sheet rows 5-18)

1. File should be generated in ASCII Format with "txt" as filename extension. (row 5)
2. Each Record (including last record) must start on new line and must end with a newline character. Hex Values : "0D" & "0A". (row 6)
3. The constant values as mentioned in the file format below (values of fields viz. 'Record Type', 'Upload Type' etc.) need to be mentioned  In BLOCK letters only. i.e.. value of field 'Record Type' in case of 'File Header' should be specified as 'FH' and not 'fh'. (row 7)
4. For all amount fields decimal value with precision of 2 should be provided e.g. 1000.50, 2345.00. It may be noted that in case of certain amount fields where fractional portion is not allowed, the value should contain decimal point followed by two zeros i.e. value - 2345 will not be allowed, whereas value - 2345.00 will be allowed. (row 8)
5. For Rate at which tax Deducted (DD), decimal with precision value 4 should be provided e.g. if the rate is 2 then the same should be mentioned as 2.0000 (row 9)
6. M indicates mandatory field and  O indicates - Optional. (row 10)
7. All dates should be in 'ddmmyyyy' format. No date should be a future date. (row 11)
8. This is a ^ delimited variable field width file. This means that in case of empty spaces there is no need to provide leading '0' for numerals and trailing spaces for character fields. (row 12)
9. The total number of delimiters (i.e. "^") in any type of record should be one less than the total number of fields in the respective record. For example the total number of fields in "File Header record" is 16, hence the total no. of delimiters in 'File Header record' would be 15. (row 13)
10. Nil challans/transfer vouchers need to mandatorily have Collectee records with flag  'A' , 'B','F','K','Y','Z' in the remarks for lower or non-deduction. (row 14)
11. It is mandatory to import .csi file downloaded from TIN website (under Challan Status Inquiry tab) to verify the correctness of Challan details mentioned in the statement. (row 15)
12. TAN & TAN name present in TDS Statement should match with TAN & TAN name present under .csi file downloaded from TIN website. (row 16)
13. Changes/ Updates done in the file format is highlighted in green. (row 17)
14. At least one Collectee/collectee details should be mentioned in regular statement. Statements with zero/no Collectee/collectee details should not be allowed to validate through FVU. (row 18)
