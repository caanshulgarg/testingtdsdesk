The Ministry of Corporate Affairs has mandated that companies maintaining books of accounts using any software to use a software with audit trail feature.

We are providing an update for Shoper 9 POS, as an add-on, to adhere to this rule. Once updated, Shoper 9 will log all the changes made to the recorded transactions and masters.

This add-on for Shoper 9 Edit Log provides the capabilities to:

  • Log every update done to transactions or masters
  • View a report that shows the changes at transaction summary level or item level
    • Generate the report based on transaction date or document date
    • Configure the report views as per user preferences and save the views user-wise
    • Filter the generated report on any field
    • Compare the original value and the updated value using filter options
    • Export the report in Excel format
    • Print the report

Apply this add-on on Shoper 9 Release 2.23 or later.

Refer to Shoper 9 Edit Log.pdf, in the installation folder, for instructions on how to use the add-on.
